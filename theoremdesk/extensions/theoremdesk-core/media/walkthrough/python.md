# Python for the notebooks

1. Open the project folder.
2. Run **Create Environment**, choose **Venv**, and tick `requirements.txt` when asked which dependencies to install.
3. Open a notebook and pick the `.venv` kernel in the top-right corner.

The notebooks use SymPy, NumPy, SciPy, Matplotlib and Plotly. Python 3.11 or newer works.

TheoremDesk uses **basedpyright** for completions and type checking, so the Python extension's own language server is switched off.
