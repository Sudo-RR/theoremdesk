# LaTeX templates

**New LaTeX Document** (also under File → New File) creates a ready-to-compile document. Every class and package it needs is built into TheoremDesk, so it works offline.

| | Templates |
|---|---|
| Research papers | AMS (mathematics), APS physics (REVTeX 4.2), arXiv preprint, Elsevier, MNRAS |
| Conference papers | IEEE, ACM, Springer LNCS |
| Talks and posters | Beamer (Metropolis theme), tikzposter |
| Theses | Any university; physics PhD (hepthesis); MIT, UC Berkeley, Toronto, Washington, Edinburgh, Auckland, Illinois |
| Around submission | Project report, cover letter to the editor, response to referees |

**Reference Style for a Journal** (the book icon on a .tex file) lists journals with the style each expects and why, and sets it in your document. When a journal's own files aren't bundled (JHEP, IOP, Springer Nature, AAS, NeurIPS), it says so and uses the closest bundled style.
