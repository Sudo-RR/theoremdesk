# Your research environment

The **⊢ TheoremDesk** icon in the activity bar opens the **Environment** view. It checks:

| Tools | This project |
|---|---|
| Git | Python environment (`.venv`) and its packages |
| Python 3.10 or newer | The project's Lean version |
| Lean (elan) | Prebuilt Mathlib |
| TeX (`pdflatex`, `bibtex`) | Lean project built |
| Long file paths (Windows) | |

Click anything marked with a warning or an error to fix it. Each fix runs in its own terminal, so you can see exactly what it does. Installers may ask you to accept their terms or for administrator rights.

The status bar shows how many things are left to set up.

After installing a tool such as Python or MiKTeX, restart TheoremDesk so it can see it.
